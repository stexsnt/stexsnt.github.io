Pour les professeurs

  

    

      
Les quatre sites reposent sur le même principe : aucun compte, aucun serveur, aucune donnée d'élève transmise. La progression reste dans le navigateur de l'élève, qui peut la sauvegarder dans un fichier.

      
Pour suivre une classe, chaque élève génère depuis sa page Profil un code qu'il vous envoie. L'espace professeur transforme les codes collés en tableau de classe, avec comparaison, progrès et export CSV. Tout est calculé sur votre ordinateur.
